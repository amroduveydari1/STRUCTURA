# STRUCTURA

An architecture website exploring how design, 3D visuals, and digital experiences come together.

[Live website](https://structura-virid.vercel.app/)

### Highlights
- Architectural projects and services
- Interactive 3D project viewer
- Multilingual interface
- AI consultant and dashboard interface

**Stack:** React, TypeScript, Vite, Three.js, Google Gen AI SDK

### Run locally
```bash
npm ci
npm run dev
```
